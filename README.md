# Bancarrota Hídrica — PTAR El Salitre

Sitio web estático basado en la investigación proporcionada por el usuario.

## Archivos
- `index.html`
- `styles.css`
- `assets/` con logo, Matriz de Vester, gráfica de clasificación, ciclo hidrológico y árbol de problemas.

## Uso
Abre `index.html` en un navegador. No requiere servidor.
